Generate images with MOSS-Image, OpenMOSS's open text-to-image model with a Qwen3.5-9B text encoder. Pick the SFT or Base checkpoint in bf16 or int8; both run 50 steps with true CFG 3.0. It follows natural language, tag lists and JSON layout prompts that place text and objects.

This preset is experimental. The MOSS-Image weights are released under Apache-2.0.
