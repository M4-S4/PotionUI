Generate and edit images with FLUX 3 Image Klein, Black Forest Labs' open 5.6B image model. One preset covers both checkpoints: the distilled model renders in 16 steps without CFG, and the Base model uses true CFG over 50 steps. Edit mode takes up to 10 reference images.
