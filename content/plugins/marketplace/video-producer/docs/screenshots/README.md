# Video Producer: reference prototype next to the plugin

Each composite puts the reference interface prototype on the left and the plugin running inside PotionUI on the right. Both sides are 1440 x 900 captures of the French interface in the default project state (no selection unless the line says so), reduced to 50 % and joined into one 1440 x 450 JPEG (quality 80). The prototype side shows its own sample project ("Échappée alpine"); the plugin side shows the starter project "Aube sur le port" that the plugin opens on (see Starter project below), created by the page on the real server, with the engine set to Wan 2.1 / 2.2. The plugin no longer ships a demonstration project with simulated takes, so the content of the two halves differs by design: the lines below describe the differences of the interface, not of the content. Every screen exists in a dark and a light version: `<screen>-dark.jpg` and `<screen>-light.jpg`.

Full-size captures (1440 x 900 and 1280 x 720, plus an English series of the plugin) are not kept in the repository. The plugin halves were retaken at step 7, after the accessibility work: 24 px pointer targets on the timeline (block handles, fade handles, camera keys in their own band above the 3D plan, 24 x 24 marker pins), lighter window subtitles, focus rings on switches and on the first control of a window.

## Differences that apply to every composite

- The plugin page sits next to the 56 px PotionUI icon rail and the host page header is hidden. At 1440 px the plugin area is 1376 px wide (rail plus an 8 px scrollbar gutter reserved by the host), so columns are about 20 px narrower: storyboard thumbnails are 12 px shorter, and the layouts that wrap earlier are kept on one line.
- Status bar: a `FR` / `EN` language button replaces the prototype label, and the active tool reads "Outil Sélection (A)" instead of "Outil : Sélection (A)". The page saves the starter project on the server as soon as it opens, so the project bar reads "Enregistré à" and the time of that save.
- Shortcut hints follow the platform (`Ctrl+G` instead of `⌘ G`) and decimals follow the locale (`6,0 s` instead of `6.0 s`).
- Hand-made controls are replaced by host components (Button, IconButton, Tooltip, Badge, SegmentedControl, Alert, Switch): labels are weight 500 instead of 400, secondary fills are one step lighter (`surface-3` instead of `surface-2`), badges are 22 px tall with wider padding where the prototype chips are 20 px, and settings toggles are 44 x 24 px switches instead of checkboxes.
- The engine selector lists the presets of the instance ("Wan 2.1 / 2.2"), grouped by the backend names given by the host, instead of "ComfyUI · RTX 4090".
- Vocabulary is unified: "Instruction locale" (prototype: "Prompt de plan", "Instructions locales du plan"), "Control video" (prototype: "Vidéo de contrôle", "contrôle"), "Sous-titres".
- Chips drawn over images (shot numbers, durations, scope tags, take letters) use a dark scrim with white text in both themes, as in the prototype. Status labels on the take thumbnails (draft, final, to redo) are white instead of tinted.
